# olist-customer-satisfaction
Predicting customer dissatisfaction for Olist e-commerce marketplace

# Прогноз удовлетворённости клиентов для маркетплейса Olist

Проект посвящен предсказанию рисков получения низких оценок (1–2 звезды) от клиентов Olist до момента написания отзыва, на основе данных о логистике и заказе.

## 📌 Архитектура проекта и данные
1. **База данных SQLite:** Проект использует 9 связанных реляционных таблиц Olist E-commerce.
2. **SQL-витрина:** Признаки агрегированы и собраны с помощью SQL-запросов (JOIN, GROUP BY) прямо в БД.
3. **Целевая переменная:** Бинарный флаг `is_dissatisfied` (1 — оценка 1–2 звезды, 0 — 3–5 звезд). Дисбаланс классов: ~12.8% негативных отзывов.

## 📊 Результаты моделей (ML)
Для борьбы с дисбалансом использован параметр `class_weight='balanced'`.

| Модель | ROC-AUC | Recall (класс 1) | Precision (класс 1) | F1-Score (класс 1) |
| :--- | :---: | :---: | :---: | :---: |
| Logistic Regression | 0.7375 | 0.59 | 0.28 | 0.38 |
| **Random Forest** | **0.7539** | **0.52** | **0.40** | **0.45** |

- **Победитель:** `Random Forest`. Модель в 3 раза эффективнее случайного угадывания и перехватывает >50% негативных отзывов.
- **Главные факторы риска:** Задержка доставки относительно обещания (`delivery_delay_days`) и общее время доставки (`delivery_time_days`) суммарно определяют >70% важности модели.

## 💡 Бизнес-рекомендации
